# Synth VS Code Extension

This extension integrates Synth (the intent layer for Git) directly into VS Code.

## Requirements
This extension requires the Synth daemon to be running locally.
Run `synth daemon start` in your terminal to start it.

## Commands
- **Synth: Ping Daemon**: Check if the Synth daemon is reachable and running.

Note: This extension is currently in local development and not yet published.
